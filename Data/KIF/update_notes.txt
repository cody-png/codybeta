KIF Beta 0.21.68
- Mods: a mod's pictures and sounds stay in its own folder and the game uses them from there, so a mod never overwrites a game file. Mods an older KIF installed are tidied once and the game's own pictures come back.
- Mods: a folder with only pictures and sounds is a mod. When two mods have the same picture, the one that loads later wins.
- Mods: Uninstall a mod from Installed (USE on it). Its settings are set aside outside your save and come back if you install it again.
- Mods: new Modpacks and Share Code tabs. Install a set of mods at once, or copy a code for your mods and give it to a friend (Mod Manager 2.0 codes work too).
- Mods: at start-up, after KIF's own update check, the game tells you when your mods have updates.
- Mods: a third catalog, KIF Beta Mods.
- Options: a choice a mod adds to a setting no longer shows another choice's description.
